# dev2hedge

个人量化 / 对冲 / AI 相关笔记库（Obsidian → GitHub Pages），已启用最小 GEO（生成式引擎优化）元数据。

## 在线地址

- 站点：<https://alphaveteran.github.io/dev2hedge/>
- Sitemap：<https://alphaveteran.github.io/dev2hedge/sitemap.xml>
- RSS：<https://alphaveteran.github.io/dev2hedge/feed.xml>

## 工作流

1. 在 Obsidian 打开本目录作为库根目录
2. 在 `_posts/` 写作；新建文用 `_templates/Jekyll模板.md`（含 `description` 等字段）
3. 推送到 `main` 后 GitHub Actions 自动部署

详见 [DEV2HEDGE.md](DEV2HEDGE.md)。
