# dev2hedge

个人量化 / 对冲 / AI 相关笔记库（Obsidian → GitHub Pages）。

## 在线地址

<https://alphaveteran.github.io/dev2hedge/>

## 工作流

1. 在 Obsidian 打开本目录作为库根目录
2. 在 `_posts/` 写作；新建文可用 `_templates/Jekyll模板.md`
3. 推送到 `main` 后 GitHub Actions 自动部署
