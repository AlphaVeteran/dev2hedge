中国A股有哪些可以AI接入的模拟实盘？

在 A 股市场，由于监管对“柜台交易系统（OMS/EMS）”以及外部 API 接入有着极其严格的合规要求，散户或独立开发者很难像在海外美股或加密货币市场那样，直接获得一个官方提供的 `api_key` 去调用模拟盘。

但是，作为一个拥有计算机软件背景的“海盗式”极客，你依然可以通过以下**四种主流的、且完全支持 AI（Python/Agent）接入的 A 股模拟盘方案**来练兵：

---

### 方案一：量化金融平台（最推荐，门槛最低的“全功能沙箱”）

国内目前有几家非常成熟的“网页端+研究环境”的量化平台。它们为你免费提供云端服务器、A 股全量历史数据，并内置了高仿真的**模拟仿真（Paper Trading）柜台**。

- **代表平台：**
    
    - **聚宽 (JoinQuant)：** 目前对独立极客、程序员最友好的平台，其 API 设计极其符合 Python 逻辑。
        
    - **同花顺 SuperMind：** 依托同花顺强大的基础数据，提供 `tick_trade_api`，支持直接在研究环境中通过代码进行模拟仿真交易。
        
    - **聚宽 / 优矿 (UQuant) / 掘金量化 (MyQuant)**。
        
- **如何与 AI 结合：**
    
    你不需要在这些平台上写全部的 AI 逻辑。你可以在你本地的 **Cursor** 或本地 Python 环境中运行你的大模型 Agent（进行文本情绪分析、策略推演），得出买卖信号。然后，**通过 Webhook 或这些平台提供的客户端 API（例如聚宽的本地 Python SDK），将信号远程推送到平台上的模拟盘账户中自动下单。**
    

---

### 方案二：富途开放接口 (Futu API / OpenD)

如果你想体验最接近华尔街标准、高自由度、低延迟的对冲基金底层架构，富途（Futu OpenD）是目前独立开发者能找到的最佳选择。

- **运作原理：**
    
    富途提供了一个名为 **OpenD** 的网关程序。这个程序安装在你的本地或云端服务器上，它以自定义 TCP 协议对外暴露接口，与编程语言无关。你只需要用 Python 下载 `futu-api` 包，连接本地的 OpenD 即可。
    
- **优势：** **真实交易和模拟交易使用完全同一套 API 接口。** 它的模拟盘（Paper Trading）全面支持 A 股通（沪股通/深股通）的标的。
    
- **极客玩法：** 你的 AI Agent 可以 24 小时监控行情，直接调用 Futu API 获取实时的订单簿（Order Book）快照，然后通过 Python 一行代码发送模拟买卖指令。未来如果你想切换到实盘（如港美股或 A 股通），**代码一行都不需要改，只需要把账户 ID 从模拟转为实盘即可。**
    

---

### 方案三：开源轻量级交易框架（QMT / PTrade 模拟环境）

随着近年国内私募量化的大爆发，“券商量化柜台”开始向资金量稍大一点的个人客户开放（通常门槛在 10万 到 50万 人民币不等，部分券商为了获客可以极低门槛开通）。

- **核心工具：** **QMT（迅投量化终端）** 或 **PTrade**。
    
- 这是一个安装在 Windows 电脑上的券商官方客户端，但它们内嵌了非常强大的 **Python 极速策略执行引擎**。
    
- **玩法：** 券商开通 QMT 后，你可以使用它的**原生模拟系统**。它提供本地的 `XtQuant` 库。你可以直接在本地用 Python 启动你的 AI 模型，通过 QMT 的本地端口，进行全自动、零延迟的日内模拟撮合。
    

---

### 方案四：最硬核的“海盗玩法”——基于 UI 自动化的安卓模拟器

如果你不想受任何平台 API 权限的限制，也不想在券商开户，只想黑进市面上最普通的模拟炒股 APP（如同花顺、东方财富的模拟炒股），程序员有自己专属的暴力美学：**UI 自动化自动化。**

- **架构设计：**
    
    1. 在你的电脑上安装一个安卓模拟器（如雷电模拟器、夜神模拟器），在里面登录同花顺 APP 的模拟炒股账号。
        
    2. 利用 Python 的 UI 自动化测试框架（如 `uiautomator2` 或 `Appium`），通过 ADB（Android Debug Bridge）直接控制模拟器。
        
- **效果：**
    
    你的 AI 策略在本地算出应该买入“贵州茅台” 100 股。你的 Python 自动化脚本（如开源项目 `THSTrader` 的变种逻辑）会自动控制模拟器：点击搜索框 $\rightarrow$ 输入 600519 $\rightarrow$ 点击买入 $\rightarrow$ 输入 100。
    
- **意义：** 虽然这种方法看起来有点“土法炼钢”，并且存在一定的延迟（大约 1-2 秒），但它**彻底打破了规则限制**。它让你拥有了对任意封闭系统的“伪 API 接入权”，是非常锻炼软件工程与自动化控制能力的黑客实践。

## 🛠️ 下一步行动建议：一人基金的脚手架搭建

作为计算机毕业的年轻人，建议你从 **【方案一（聚宽/同花顺云端API）】** 开始起步，这是最容易闭环的。

你可以尝试用 **Cursor** 编写一个最简单的本地脚本：

1. 调用大模型（如 DeepSeek 或 Claude）读取一份今天的宏观经济新闻或行业公告，输出 `1`（买入）或 `0`（观望）。
    
2. 使用聚宽的本地 SDK（`jqdatasdk`），在检测到 `1` 时，自动远程向你的云端模拟账户发送一笔买入指令。
    

当你看到云端模拟盘的资产数字随着你的 AI 代码而跳动时，你的“一个人的对冲基金”就已经正式扬帆起航了。
